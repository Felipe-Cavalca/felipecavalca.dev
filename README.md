# felipecavalca.dev

Site estatico pessoal pronto para GitHub Pages.

## Estrutura

- `index.html`: conteudo da pagina
- `styles.css`: estilo visual
- `script.js`: interacoes simples
- `.github/workflows/deploy-pages.yml`: deploy automatico no GitHub Pages

## Publicar no GitHub Pages

1. Faca push para a branch `main`.
2. No GitHub, abra `Settings > Pages`.
3. Em `Build and deployment`, selecione `GitHub Actions`.
4. Aguarde o workflow `Deploy static site to GitHub Pages` finalizar.

## Personalizacao rapida

- Atualize nome, bio e links em `index.html`.
- Troque cores e tipografia em `styles.css`.
- Adicione seus projetos na secao `Projetos em destaque`.
